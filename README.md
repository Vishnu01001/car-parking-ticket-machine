Car Parking Ticket Machine

A beginner-friendly C++ console program that simulates a simple parking ticket machine and calculates parking charges based on the duration of parking.

Features

- Takes parking duration as user input
- Calculates parking charges based on parking time
- Handles invalid parking-time input
- Displays the calculated parking fee
- Uses a class and object-based approach

Concepts Used

- C++
- Classes and Objects
- Functions
- Conditional Statements
- User Input and Output
- Basic Problem Solving
- Arithmetic Operations

How It Works

The user enters the number of hours their vehicle has been parked. The program processes the input and calculates the parking fee according to the defined pricing rules.  

Example

Enter the time (in hours): 3

Your Total Fee: ₹130

Purpose

This project was created as part of my journey learning C++ and practicing how to apply programming fundamentals to real-world inspired problems.

What I Learned

Through this project, I practiced using classes and objects, conditional logic, functions, user input, and basic calculations to build a practical console-based application.
